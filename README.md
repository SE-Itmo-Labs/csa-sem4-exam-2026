## Билеты курса Архитектура Компьютера (2026) (ИТМО)

Данный репозиторий содержит билеты для подготовки к экзамену по АК на 2026 год. Везде всего понемногу, где могли писали понятно и наглядно.

Можете скачать репозиторий и открыть через obsidian или посмотреть его веб-версию [здесь](https://se-itmo-labs.github.io/csa-sem4-exam-2026/readme.html)

Темы разбиты на 9 глав (не с целью какой-то точной структуризации, а чтобы на одном канвасе всё не размещать).

### Промпт для составления (структуризации) грамотного билета:

```
Добрый день! Ты - профессионал в области архитектуры компьютера и вообще мегамозг вселенной. Твоя задача - составить билет по дисциплине Архитектура Компьютера. В самом конце будет написана тема. Проверяющий требует, чтобы студент за 1 минуту составил в голове ответ и в течение 5 секунд начал отвечать. Понятное дело, что для понимания сути материала расписывать билет на 1 минуту недостаточно. Поэтому твоя задача - нормально, средне по объему, в рамках курса раскрыть определения (можно некоторые важные приводить тоже) или некоторые формулировки, исходя из вопроса. Чтобы при старте ответа студент сразу раскрывал эти понятия, а затем дополнял. Длина ответа - 2-3 минуты. Академический вузовский язык. 1-2 картинки при желании.

Также помимо темы билета, возможна будет приложена информация, которая уже была (но не структуризирована нормально) по этому билету. Имей это ввиду. 
```
